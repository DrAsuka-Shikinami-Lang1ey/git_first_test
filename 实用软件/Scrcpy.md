- **鼠标键盘控制手机**：左键点击、右键返回、滚轮滑动，电脑键盘可以直接在手机里输入文字。
- **电脑和手机互相复制粘贴**：比如电脑复制一段文字，可以直接粘贴到微信、浏览器输入框里；反过来也可以。
- **录制手机画面**：不用 OBS，也可以直接让 scrcpy 把手机画面录成视频。
- **手机黑屏，但电脑继续显示**：适合长时间操作，手机本身屏幕不用一直亮着。
- **无线连接**：第一次 USB 配好以后，可以通过 Wi-Fi/TCP-IP 连接，后面不一直插数据线。
- **拖文件到手机**：可以把电脑里的普通文件拖进 scrcpy 窗口，传到手机；把 APK 拖进去还可以直接安装。
- **手机声音传到电脑**：Android 11 及以上支持音频转发，你的 vivo X80 系统版本通常满足这个条件。
- **调画质和延迟**：可以限制分辨率、码率、帧率，让投屏更清晰或者更流畅。
- **游戏手柄控制**：scrcpy 也支持把连接在电脑上的游戏手柄映射给手机。

比如你现在最值得试的三个命令：

```
scrcpy --turn-screen-off
```

手机屏幕熄灭，但电脑上继续操作。

```
scrcpy --record phone.mp4
```

边投屏边录制，视频保存成 `phone.mp4`。

```
scrcpy -m 1920
```

把最大分辨率限制到 1920，通常能降低延迟。

如果你想把它用得更像“电脑操作手机”，其实还能做得更舒服：**无线连接 + 手机熄屏 + 电脑键鼠控制 + 声音走电脑**，这样基本就像手机运行在电脑窗口里一样。


## 无线连接
使用之前，先打开开发者模式，开启USB调试功能
先让 **vivo X80 和电脑连接同一个 Wi-Fi**，然后 USB 先连一次手机，在 scrcpy 文件夹的 PowerShell 里运行：

```
.\scrcpy.exe --tcpip
```

它会自动：

```
通过 USB 找到手机
↓
获取手机 IP
↓
开启 ADB TCP/IP
↓
建立 Wi-Fi 连接
↓
启动 scrcpy
```

然后你就可以把 USB 线拔掉，后续继续无线控制。

如果以后已经开启了 TCP/IP，而且你知道手机 IP，例如：

```
192.168.1.105
```

可以直接：

```
.\scrcpy.exe --tcpip=192.168.1.105
```

默认使用 5555 端口，也可以明确写：

```
.\scrcpy.exe --tcpip=192.168.1.105:5555
```
