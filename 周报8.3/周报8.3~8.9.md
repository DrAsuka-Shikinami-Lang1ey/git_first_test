## 修改 Flash 映射模式

`set_csa.850` 是汇编源文件。

![](../U2X/picture/Pasted%20image%2020260804170308.png)

当前只显示一个 8 MB Flash，说明芯片处于 Single Map Mode（单映射模式）。此时，`OPBT12` 的低两位为 `01`。

如需改为两个 4 MB Flash，应将 `OPBT12` 设置为：

```text
OPBT12 = 0xFFFFFFFC
```

修改后，低两位变为 `00`，表示 Double Map Mode（双映射模式）。

### 在 J-Flash 中修改映射模式

将 `OPBT12` 的末字节由 `FD` 修改为 `FC`。

![](../U2X/picture/Pasted%20image%2020260805101355.png)

### 修改步骤

![](../U2X/picture/Pasted%20image%2020260805102101.png)

使用 VS Code 打开实际工程路径下的 `set_csa.850` 文件，修改 `OPBT12`。保存文件后，返回 MULTI，重新编译并生成新的 ELF 文件。

![](../U2X/picture/Pasted%20image%2020260805102313.png)

如果每次都固定在 `0x00390000` 处失败，可按以下顺序排查。

此前可能烧录过 Block Protection 配置，导致 Block 63～69 中的部分或全部区域被禁止擦除。

## 处理 MCAL 生成器路径解析错误

### 问题现象

MCAL 生成器没有以官方模板所在目录为基准解析 `..\`，而是以脚本工作目录为基准进行解析，导致相对路径错误。

![](../U2X/picture/Pasted%20image%2020260806101859.png)

### 解决方法

将配置改回：

```batch
set CfgTrxml=%RootDir%\scripts\src\Sample_Application_U2Cx.trxml
```

![](../U2X/picture/Pasted%20image%2020260806101620.png)

在以下目录中复制 `dr7f702606a_0.h`，并将副本重命名为 `dr7f702606_0.h`：

```text
D:\u2c4\work\AUTOSAR_RH850_U2Cx_MCAL_Ver22.01.01\X2x\U2Cx\common_family\include\ghs
```

![](../U2X/picture/Pasted%20image%2020260806102300.png)

## 处理 CAN 与 LIN 全局变量重名

CAN 和 LIN 的桩代码同时定义了名为 `GucWakeupCount` 的全局变量，但两处定义的类型不同：

- CAN：`uint8 GucWakeupCount;`
