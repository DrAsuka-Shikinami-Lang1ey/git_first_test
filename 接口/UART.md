# **Universal Asynchronous Receiver/Transmitter，通用异步收发器**。

MCU A                       MCU B
 TX  -------------------->  RX
 RX  <--------------------  TX
 GND ---------------------  GND

| 配置项               | 是否必须     | 作用                  | 常见配置                | 注意事项                       |
| ----------------- | -------- | ------------------- | ------------------- | -------------------------- |
| **TX / RX 引脚**    | 必须       | 指定 UART 发送、接收使用哪个引脚 | TXD、RXD             | TX 接对方 RX，RX 接对方 TX        |
| **UART 通道**       | 必须       | 选择使用哪个 UART 外设      | UART0、SCI0、SCI1 等   | 引脚必须支持对应通道功能               |
| **波特率 Baud Rate** | 必须       | 决定数据传输速度            | 9600、115200、921600  | **通信双方必须一致**               |
| **数据位 Data Bits** | 必须       | 一帧中有效数据的位数          | 通常 8 bit            | 双方必须一致                     |
| **停止位 Stop Bits** | 必须       | 表示一帧数据结束            | 通常 1 bit            | 双方必须一致                     |
| **奇偶校验 Parity**   | 必须配置     | 是否进行简单错误检查          | None / Even / Odd   | 即使不用，也要设成 None；双方必须一致      |
| **工作模式**          | 必须       | 决定发送、接收还是双向         | TX+RX               | 普通 UART 通常选收发模式            |
| **UART 时钟源**      | MCU 一般需要 | UART 根据它计算波特率       | PCLK、PCLKB 等        | 通常由 FSP 自动处理，但时钟必须有效       |
| **GPIO 电气属性**     | 一般需要     | 决定引脚电气行为            | Peripheral Function | TX/RX 通常配置成外设功能，而不是普通 GPIO |
| **中断**            | 可选       | 发送/接收完成后通知 CPU      | RXI、TXI、TEI、ERI     | 使用中断收发时配置                  |
| **中断优先级**         | 可选       | 决定 UART 中断优先级       | Priority 0~15 等     | 只有启用中断时需要                  |
| **Callback 回调函数** | 可选       | UART 事件发生时执行程序      | `uart_callback()`   | FSP 中断方式常用                 |
| **FIFO**          | 可选       | 缓存多字节数据             | Enable / Disable    | 数据量较大时有用                   |
| **DMA / DTC**     | 可选       | 自动搬运 UART 数据        | Enable / Disable    | 大量、高速通信时使用                 |
| **硬件流控**          | 可选       | 防止接收方来不及处理          | RTS / CTS           | 普通两线 UART 通常不用             |
