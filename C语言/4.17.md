## 数组
### 1.一维数组的创建和初始化
#### 1.1数组的创建
**数组是一组相同元素的集合**
```
type_t   arr_name  [const_]
//type_t 是指数组的元素类型
//const_n 是一个常量表达式，用来指定数组的大小
int arr[];
char ch data1[20];
double data2[15+5];
//C99标准之前数组的大小必须是常量或则常量表达式
//C99之后，数组的大小可以是变量，为了支持变长数组（数组的大小可以通过变量改变）

```
#### 1.2数组的初始化
```
int arr[10] = {1,2,3};
不完全初始化，剩余的元素默认初始化为0


char ch3[] = {'a','b','c'};
char ch4[] = {"abc"};
前一个数组中只有三个数，后一个数组里面有四个数，因为字符串默认会有一个\0


```
#### 1.3一维数组的使用
```
[],下标引用操作符，就是数组访问的操作符
arr[4];其实找的就是数组中下标为4的数（数组的编号也就是下标都是从0开始



```
#### 1.4一维数组在内存中的存储
随着数组下标的增长，元素的地址，也在有规律的递增，由此得出结论，**数组在内存中是连续存放的**
