## 处理 MCAL 生成器路径解析错误

### 问题现象

MCAL 生成器没有以官方模板所在目录为基准解析 `..\`，而是以脚本工作目录为基准进行解析，导致相对路径错误。

![](picture/Pasted%20image%2020260806101859.png)

### 解决方法

将配置改回：

```batch
set CfgTrxml=%RootDir%\scripts\src\Sample_Application_U2Cx.trxml
```

![](picture/Pasted%20image%2020260806101620.png)

在以下目录中复制 `dr7f702606a_0.h`，并将副本重命名为 `dr7f702606_0.h`：

```text
D:\u2c4\work\AUTOSAR_RH850_U2Cx_MCAL_Ver22.01.01\X2x\U2Cx\common_family\include\ghs
```

![](picture/Pasted%20image%2020260806102300.png)

### 正确结果

![](picture/Pasted%20image%2020260806102637.png)

### 准备配置文件

1. 在 `scripts` 目录下新建文件夹：

   ```text
   profile
   ```

2. 找到当前 DaVinci 导出的配置文件：

   ```text
   D:\u2c4\work\U2C4_LED_BLINK\tools\mcal\Config\ECUC\u2c_2211.ecuc.arxml
   ```

3. 将该文件复制到新建的 `profile` 文件夹中。

4. 将复制后的文件重命名为：

   ```text
   all.arxml
   ```

## 处理 CAN 与 LIN 全局变量重名

CAN 和 LIN 的桩代码同时定义了名为 `GucWakeupCount` 的全局变量，但两处定义的类型不同：

- CAN：`uint8 GucWakeupCount;`
- LIN：`uint8 GucWakeupCount[NUM_CPU];`
