# 一、产品特点
RH850/F1KM 是一款具有 G3KH CPU 核心的 32 位单片微控制器。
F1KM 的主要特点是低功耗、高计算处理能力以及丰富的内部外设功能。
为了在各种应用中降低供电电流，提供了多种节能措施。
例如，低功耗采样器（LPS）可以在无需 CPU 核心参与的情况下轮询输入到模拟和数字输入引脚的信号；DeepSTOP 模式可以关闭微控制器大部分电路的电源。
# 二、应用
RH850/F1KM 非常适合汽车电子，例如车身控制模块（BCM）、网关、暖通空调（HVAC）、照明模块以及许多其他应用


# 概念
**FPU单精度**：浮点运算单元是 CPU 内部的一个**专用硬件模块**，专门用来加速**带小数点的数字运算**。单精度：32位浮点数，约为7位有效十进制数。

**Processor Element Guard (PEG)**：处理器单元保护。
**Memory Protection Unit (MPU)**：内存保护单元。
**Internal Peripheral-device Guard (IPG)**：内部外围设备保护器。

### 1.1引脚
表示物理引脚。每个引脚由唯一的引脚编号表示。一个引脚可以用于多种模式。每个引脚都被分配一个反映其功能的名称，该功能由所选模式决定。
### 1.2Port group 
Denotes a group of pins. All the pins of a specific port group are controlled by the same port control register.
端口组 
表示一组引脚。特定端口组的所有引脚均由同一个端口控制寄存器控制。
### 1.3Port mode and ports
 A pin in port mode works as a general-purpose input/output pin. It is then called “port”. The corresponding name is Pn_m. For example, P0_7 denotes port 7 of port group 0. It is referenced as “port P0_7”.
**一个引脚工作在端口模式时，它就是一个通用输入输出引脚（GPIO）。这时候，我们就把这个引脚叫做 “端口（Port）”。**
**它的命名格式是 `Pn_m`：比如 `P0_7` = 第 0 组端口的第 7 号引脚，我们称呼它为 端口 P0_7。**

**端口模式**（port mode）
端口模式 = 普通 GPIO 模式 = 通用输入输出模式
### 1.4**Alternative mode 复用模式**
在复用模式下，引脚不再作为普通通用输入 / 输出（GPIO）使用，而是用来提供芯片内部外设的专属功能。
例如：外部中断、串口、SPI、定时器、ADC 等专业功能。引脚的名字，会根据你选用的功能而改变。
举例：`INTP0` 这个引脚名，代表**外部中断 0 输入功能**。
### 1.5调试引脚
JTAG 调试引脚：统一用**J 开头**的专属寄存器，互不冲突

### 1.7P寄存器  PPR寄存器
芯片引脚的真实电平，不管当前是什么模式，最终都是通过只读寄存器 `PPRn` 读出来的，只不过 `PPRn` 里读到的值，是根据不同模式由硬件自动切换来源的。
- **端口模式**：PPRn 读的是 `Pn` 寄存器里的值（软件写进去的）
- **直接控制复用模式**：PPRn 读的是**外设硬件**实际收到的电平（比如 UART RX 收到的信号）

1. **Pn 读出来的是假的**（自己写的值）
2. **想看真实引脚电平，必须读 PPR**
3. **外设接管引脚后，Pn 直接报废**
### 1.8PMC寄存器
端口模式控制寄存器
### 1.9PSR寄存器 PNOT寄存器
如果 `PSRn` 寄存器的 **第 (m+16) 位** 为 1，那么 `Pn` 寄存器中 `Pn_m` 位的值，就会被强制设置为 `PSRn` 寄存器的 **第 m 位** 的值，不用直接写 `Pn` 寄存器，就能设置 / 清除 `Pn_m` 位的电平。

`PSRn` 是一个 **32 位寄存器**，被分成了两部分：
- **低 16 位（位 0~15）**：要设置的**目标值**（1 = 高电平，0 = 低电平），对应端口组的 16 个引脚（m=0~15）。
- **高 16 位（位 16~31）**：**使能掩码**，对应 `m+16`，也就是 `m=0` 对应位 16，`m=1` 对应位 17...`m=15` 对应位 31。
```c
//1. 把 P0_0 设为高电平（1）
PSR0 = (1 << 16) | (1 << 0); 
// 解释：高16位的位16（m+16=0+16）设为1（使能修改），低16位的位0设为1（目标值） 
// 2. 把 P0_0 设为低电平（0）
 PSR0 = (1 << 16) | (0 << 0); 
 // 3. 同时设置 P0_0 和 P0_2 为高电平（一次操作两个引脚） 
 PSR0 = (1 << 16) | (1 << 18) | (1 << 0) | (1 << 2);
```

`PNOTn` 是专门用来**翻转电平**的快捷寄存器：
```c
// 翻转 P0_0 的电平（LED 闪烁，不用读P0的值！）
 PNOT0 |= (1 << 0);
```
### 1.10PIBC（Port Input Buffer Control）

- **作用**：**输入缓冲器使能控制**，用来开启 / 关闭引脚的输入缓冲器
- 写`1`：开启输入缓冲器，才能通过`PPR`读取引脚电平
- 写`0`：关闭输入缓冲器，引脚处于高阻态，不能读电平，同时降低功耗

从属防护是一种防止特定总线主设备的未授权访问的功能，由以下防护结构组成：
PE 保护器 (PEG)

具有系统互连的处理器单元（PE）支持“内部外设保护”（IPG），该功能可保护外设的寄存器免受无效访问。

## 4.4 DMA设置PEG
**当从DMA访问PE（处理单元）中的本地RAM和保持RAM时，必须设置PEGSP寄存器、PEGGnMK寄存器（n = 0到3）、PEGGnBA寄存器（n = 0到3）和PDMDnDMyiCM寄存器（yi = 00到07，10到17）**

| **PEGSP**           | PE保护总开关，启用/禁用保护功能         |
| ------------------- | ------------------------- |
| **PEGGnMK** (n=0~3) | **保护组掩码寄存器，定义保护区域大小**         |
| **PEGGnBA** (n=0~3) | **保护组基地址寄存器，定义保护区域起始地址和访问权限** |
| **PDMDnDMyiCM**     | **DMA通道控制寄存器，配置DMA传输模式**      |
## 4.5 DMA专业术语
**DMA 周期**： 指一系列动作，包括从**源地址**指定的位置读取由**传输大小**（8/16/32/64/128 位）（我做的就是一个字节的传输）指定数量的数据，并将其写入到**目标地址**指定的位置。DMA 周期的前半部分（读取部分）称为**读周期**，后半部分（写入部分）称为**写周期**。
