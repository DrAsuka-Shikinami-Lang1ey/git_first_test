## 一、“SPI 的 SO 和 SI 方向”——检查数据线有没有接反
MCU 是主机，外接 SPI Flash 是从机

MCU                                                          SPI Flash
SO／MOSI  ────────────────→    SI／DI
SI／MISO  ←────────────────     SO／DO
SCK       ────────────────→         SCK
CS        ────────────────→           /CS

## 二、“烧录用的转接口设计时，要将 3 个 GND 连在一起”——保证烧录接口共地及回流完整
数字信号的高低电平是相对于地判断的。如果烧录器和目标板的地没有可靠连接，即使数据线接对，双方看到的信号电压也可能不同，导致连接失败或烧录不稳定。
## 三、“从 DeepSTOP 模式唤醒的唤醒源需要位于 AWO 区域”——休眠后，负责检测唤醒的电路必须仍然工作
`DeepSTOP` 是一种深度低功耗模式。为了降低功耗，MCU 会停止部分时钟，并可能关闭部分内部电源域。


原理图和软件要配合检查：

1. 查手册中的 DeepSTOP 唤醒源列表，选择支持的引脚或内部事件。
2. 确认外部唤醒器件在休眠期间仍具备必要供电。
3. 确认上拉电源在休眠时仍有效，电平满足 MCU 要求。
4. 配置唤醒使能、边沿或电平条件，并按手册处理唤醒标志。
5. 确认唤醒后的恢复流程；不能默认所有状态都保留、程序直接从原处继续
