## 时钟配置核心代码
```c
WPROTR.PROTCMD1 = _WRITE_PROTECT_COMMAND;
//时钟寄存器属于芯片核心敏感寄存器，默认硬件上锁，必须这样发送指令才能修改配置，防止误操作死机。
```


```c
CLKCTL.CKSC_PPLLCLKS_CTL = _CGC_PPLLCLK_SOURCE_EMCLK;
CLKCTL.CKSC_PPLLCLKS_CTL = (uint32_t) ~_CGC_PPLLCLK_SOURCE_EMCLK;
CLKCTL.CKSC_PPLLCLKS_CTL = _CGC_PPLLCLK_SOURCE_EMCLK;
//RH850硬件强制时序要求，写值-取反-重写值，才能确定是真的要修改时钟配置，~表示二进制0和1相互转变

```

```c
while ((CLKCTL.CKSC_PPLLCLKS_ACT & _CGC_PPLLCLK_SOURCE_ACTIVE) != _CGC_PPLLCLK_SOURCE_EMCLK)
```

- **`CLKCTL.CKSC_PPLLCLKS_ACT`**
    
    PLL 时钟d源的**当前状态寄存器**（硬件自动返回的真实状态）
    
    ✅ 里面包含：真正的时钟源状态
    
    ❌ 同时包含：硬件保留的**无用位 / 垃圾位**（值随机，没用）
    
- **`_CGC_PPLLCLK_SOURCE_ACTIVE`**
    
    官方定义的**掩码（遮罩）**
    
    作用：只保留「有用的状态位」，把其他位全部屏蔽（变成 0）
    
- **`&`**
    
    
    规则：**两位都是 1 → 结果为 1；只要有一个 0 → 结果为 0**

### CPU时钟以及频率分配
```c
WPROTR.PROTCMD1 = _WRITE_PROTECT_COMMAND;
CLKCTL.CKSC_CPUCLKD_CTL = _CGC_CPU_CLK_DIVIDER_1;//配置分频系数为1（不分频）
CLKCTL.CKSC_CPUCLKD_CTL = (uint32_t) ~(_CGC_CPU_CLK_DIVIDER_1);
CLKCTL.CKSC_CPUCLKD_CTL = _CGC_CPU_CLK_DIVIDER_1;
while (CLKCTL.CKSC_CPUCLKD_ACT != (_CGC_CPU_CLK_DIVIDER_1))
{
    NOP();
}
```


- CPU 时钟源 = **EMCLK（外部晶振）** → 经过 PLL 倍频后，是**芯片最高、最稳定的高频时钟**
- 配置 分频系数=1→ **CPU 直接跑满最高频率**，不降低速度
### ( CGC_CPU_CLK_DIVIDER_1)加括号是因为它是宏定义，编译时是一串二进制数，不加括号进行运算时可能会导致运算出错)
### PROTCMD0：保护组 0 → 控制看门狗、定时器、ADC等低速外设 
### PROTCMD1：保护组 1 → 控制CPU、PLL、高速通信 瑞萨把时钟分两组保护，不同外设用不同解锁指令
### 看门狗（WDTA）

/*瑞萨硬件强制：三次写入看门狗时钟配置*/

### TAUJ 定时器
**TAUJ = Timer Array Unit J**

是**瑞萨 RH850 车载 MCU 里的 16 位通用定时器**
### 为什么用 **HSOSC** 时钟？

- TAUJ 需要**不低的精度**做计时 / PWM
- 不用外部晶振 EMCLK（浪费资源）
- 不用低速晶振 LSOSC（速度太慢）
- **HSOSC 高速内部时钟** 最适合通用定时器
### 实时时钟RTCA
- `CLK_SOURCE_DISABLE` = **关闭时钟源**
- `CLK_DIVIDER_DISABLE` = **关闭时钟分频**
    
    两个都关闭 = **RTCA 实时时钟彻底断电，无法工作**
