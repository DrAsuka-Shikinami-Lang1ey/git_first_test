## DSI3
E521.44 通过 DSI3 发送的是 **CRM 命令帧**（32 bit），不是寄存器地址：

```
DSI3 CRM 命令帧格式：┌──────────┬──────────┬──────────┬──────────┐│ PhysAddr │  CMD     │  Data    │  CRC     ││ 4 bit    │  4 bit   │  16 bit  │  8 bit   │└──────────┴──────────┴──────────┴──────────┘
例如：CMD = 0x1 → "启动标准测量"      CMD = 0x2 → "启动高级测量"      CMD = 0x8 → "配置数据访问"（这个才是写参数）
```
## 为什么要500k的时钟？
E521.44 需要一个外部时钟参考信号才能工作。这里用 RA6M3 的 **GPT13 定时器**在 **P504** 引脚产生 **500kHz、50% 占空比**的方波，送给 E521.44 的 CLKREF 引脚

#### 循环等待 RFC 变高
```c
for (g_e521_rfc_wait_ms = 0U; 
g_e521_rfc_wait_ms < E521_RFC_TIMEOUT_MS; // 最多等 100ms 
g_e521_rfc_wait_ms++) 
{ R_IOPORT_PinRead(&g_ioport_ctrl, E521_RFC_PIN, &rfc_level); 
g_e521_rfc_level = rfc_level; 
if (BSP_IO_LEVEL_HIGH == rfc_level)
  { g_e521_rfc_ready = true; // ✅ 就绪！
    break; // 跳出循环 
  } 
_BSP_SoftwareDelay(1U, BSP_DELAY_UNITS_MILLISECONDS); // 等 1ms 再查 
}
```
# E524.17连接了E521.44的CN1,E521.44通过DSI3读到E524.17配置
## 完整程序流程
启动500 kHz CLKREF
→ RESB拉低5 ms
→ 释放RESB并等待RFC
→ 打开RSPI0
→ 读取E521.44 ID，确认SPI仍正常
→ CRC自检
→ 写DSI_CFG = 0x31
→ 发送E524.17只读配置命令，确认DSI3链路和传感器地址
→ 上传单传感器TDMA
→ 验证TDMA
→ 发送STA标准测量命令
→ 等待至少一个PDCM周期
→ 启动有限数量PDCM脉冲
→ 轮询PD0并读取PDCM缓存
→ 解析F6/F7回波和F10测量结束帧
