# 主要功能
1. **两个独立 DSI3 接口**
    - 符合 DSI3 总线标准
    - 每通道最多支持 **15 个 DSI3 从设备**
    - 每包有效载荷 **2~63 字节**
    - 通信速率最高 **666 kbit/s**
2. **三种工作模式**
    - **CRM**（Command Response Mode）— 命令响应模式
    - **PDCM**（Periodic Data Collection Mode）— 周期数据采集模式
    - **DM**（Discovery Mode）— 发现模式（自动地址分配）
3. **支持的总线拓扑**
    - 菊花链总线（Daisy chain）
    - 并行总线（Parallel bus）
    - 点对点（Point-to-point）
4. **高级 SPI 协议**
    - 命令队列 + 自主执行控制
    - 大数据缓冲区，减少主机控制器的中断负载
    - 专用数据通道缓冲区
5. **宽 IO 电压范围**：1.8V ~ 5V
